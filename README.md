## 📁 Topics Covered

| Topic | Description |
|---|---|
| 🔢 [Array](./Array) | Traversal, searching, subarray & manipulation problems |
| 🔤 [String](./String) | Pattern matching, parsing, and manipulation problems |
| 🎯 [Binary Search](./BinarySearch) | Search space reduction techniques on sorted data |
| 🤑 [Greedy](./Greedy) | Locally optimal choice strategies |
| 📊 [Sorting](./Sorting) | Classic sorting algorithms & applications |
| 🌐 [Graph](./Graph) | BFS, DFS, shortest path, and graph traversal problems |
| 🌳 [Tree](./Tree) | Binary trees, BSTs, traversals, and tree-based problems |
| ⚙️ [Bit Manipulation](./BitManipulation) | Bitwise tricks and optimization problems |
| 📚 [Stack](./Stack) | Stack-based problem solving |
| 🧮 [DP](./DP) | Dynamic programming — memoization & tabulation |
| 🔗 [Linked List](./LinkedList) | Singly/doubly linked list operations & problems |
| 🪟 [Sliding Window](./SlidingWindow) | Fixed & variable size window techniques |
